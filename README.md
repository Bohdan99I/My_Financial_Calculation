# Personal Finance Tracker

**МійОблік** — вебзастосунок для обліку особистих фінансів, який допомагає відстежувати доходи та витрати, контролювати баланс і аналізувати фінансову активність за різні періоди.

Проєкт розроблено з використанням React, TypeScript, Tailwind CSS і Supabase.

## Основні можливості

- **Облік доходів і витрат** — створення, редагування та видалення фінансових операцій.
- **Фінансова панель** — перегляд доходів, витрат і балансу за вибраний період.
- **Поточний баланс** — розрахунок загального балансу з урахуванням початкового залишку.
- **Фільтрація операцій** — відбір фінансових записів за доступними параметрами.
- **Статистика** — аналіз доходів і витрат за вибраний період.
- **Навігація за місяцями** — перегляд фінансової активності в розрізі місяців.
- **Налаштування** — керування початковим балансом.
- **Імпорт та експорт Excel** — завантаження й вивантаження фінансових даних.
- **Адаптивний інтерфейс** — зручне використання на різних розмірах екранів.

## Встановлення та запуск

### 1. Клонування репозиторію

```bash
git clone https://github.com/Bohdan99I/My_Financial_Calculation.git
cd My_Financial_Calculation
```

### 2. Встановлення залежностей

```bash
npm install
```

### 3. Налаштування змінних середовища

Створи файл `.env` у кореневій директорії проєкту:

```env
VITE_SUPABASE_URL=your_supabase_project_url
VITE_SUPABASE_ANON_KEY=your_supabase_anon_key
```

Заміни значення на відповідні параметри свого проєкту Supabase.

> **Безпека:** не додавай файл `.env` до Git-репозиторію. Для клієнтського застосунку використовуй лише призначений для клієнтів публічний ключ Supabase. Не зберігай секретний `service_role` ключ у фронтенді.

### 4. Налаштування бази даних

У директорії `supabase/migrations/` розташована SQL-міграція для створення необхідних таблиць.

Застосуй міграцію до свого проєкту Supabase та переконайся, що налаштовані відповідні права доступу й політики Row Level Security (RLS).

### 5. Запуск у режимі розробки

```bash
npm run dev
```

Після запуску відкрий адресу, яку Vite виведе в терміналі. Типова локальна адреса:

```text
http://localhost:5173
```

### 6. Перевірка коду

Запуск ESLint:

```bash
npm run lint
```

Створення production-збірки:

```bash
npm run build
```

Попередній перегляд production-збірки:

```bash
npm run preview
```

## Модель даних

### Operation

Модель фінансової операції містить такі основні поля:

| Поле | Опис |
|---|---|
| `id` | Унікальний ідентифікатор операції |
| `date` | Дата операції |
| `type` | Тип операції: `income` або `expense` |
| `amount` | Сума операції |
| `category` | Категорія операції |
| `comment` | Додатковий коментар |

### AppSettings

Модель налаштувань містить параметри початкового балансу:

| Поле | Опис |
|---|---|
| `initial_balance` | Початковий залишок коштів |
| `use_initial_balance` | Ознака використання початкового залишку в розрахунках |
